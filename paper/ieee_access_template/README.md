# IEEE Access LaTeX template support files

Unmodified class, style, font and logo files from the official IEEE Access LaTeX template
(`ACCESS_latex_template_20260513`, downloaded 2026-11-01 from
https://ieeeaccess.ieee.org/wp-content/uploads/2026/05/ACCESS_latex_template_20260513-1-1.zip,
linked from https://ieeeaccess.ieee.org/authors/submission-guidelines/).

`scripts/build_submissions.py` copies them, with `paper/access.tex`, the shared manuscript files,
figures, tables and bibliography, into a flat folder and compiles the IEEE Access version there.
