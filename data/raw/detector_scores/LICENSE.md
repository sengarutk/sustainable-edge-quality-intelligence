# Licenses of the detector scores

The image scores in this folder are derived data computed from public benchmark images (no images are included).

* `*/mvtec/` — derived from MVTec AD (Bergmann et al., IJCV 2021; https://www.mvtec.com/company/research/datasets/mvtec-ad),
  licensed CC BY-NC-SA 4.0. These scores are shared under the same license: non-commercial use, attribution, share-alike.
* `*/visa/` — derived from VisA (Zou et al., ECCV 2022; https://github.com/amazon-science/spot-diff),
  licensed CC BY 4.0. These scores are shared under CC BY 4.0 with attribution.

The repository's MIT license covers the code only.
